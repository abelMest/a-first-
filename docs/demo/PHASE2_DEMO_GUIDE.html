Phase 2 demo guide: ADAPTIVE

Local instance (http://localhost:8710), course Data Science & Analytics for Public Health. About 15 minutes. Screenshots taken 13 November 2026. Every learner shown is a scripted test account (evidence class: dev).

Before you start

  • Docker Desktop and the Ollama app are running; http://localhost:8710 opens.
  • Reset the demo learners (about 1 minute; repeat after any rehearsal):
    cd /c/AFIRST_Backup/afirst-rebuild && bash dev/demo_phase2.sh
  • Four browser windows (separate profiles or private windows) on the course: newlearner, fasttrack, remediation (student password in dev/.env) and teacher1 (teacher password).

Do these in rehearsal, not on stage. The first time each demo learner logs in, Moodle shows a "Find your way around" tour: press Esc or click through it. The first time a learner opens Ask the course, Moodle asks them to accept its AI policy: accept it once per account. Then run the reset script again (it keeps both).

1. Opening (2 minutes)

Phase 1 recap: the course assistant answers only from approved course text, cites it and refuses everything else. Gate 1 candidate run with a local model: 0 of 10 out-of-scope questions answered, 37 of 40 course questions answered, English, French and Portuguese 6/6 each.

The problem ADAPTIVE solves: everyone gets the same sequence. An experienced epidemiologist sits through content they know; a learner who fails a Knowledge Check gets only "try again". ADAPTIVE adds a fast-track and a remediation path to the same course, with standard Moodle features.

2. The learner paths

1

The diagnostics

Window: newlearner · Pre Course Activities

Show the Placement Test (the Module 1 diagnostic) and the three optional module diagnostics: 10 questions each, from the course's own question bank.

Anyone who scores 90% or more on a diagnostic can go straight to that module's Knowledge Checks. Nobody has to take them.

2

A new learner: Knowledge Checks are locked

Window: newlearner · Module 1

Open Module 1 and click Show more under the Module 1.1 Knowledge Check.

The Knowledge Check opens when the learner completes the module, or scores high enough on the diagnostic. Either route leads to the same Knowledge Check.

3

Fast-track

Window: fasttrack · Module 2

This learner scored 10/10 on the Module 2 diagnostic. Both Module 2 Knowledge Checks are open, although the Module 2 content was never opened. In the course index on the left, Module 1's Knowledge Checks still show a lock.

The learner still has to pass the Knowledge Check, so the evidence of competence is the same. Only the time is saved.

4

Remediation: a review appears

Window: remediation · Module 1 (the core of the demo)

This learner finished Module 1.1, then scored 20% on its Knowledge Check (the pass mark is 70%). A new activity, Review: Module 1.1, has appeared under it; other learners don't see it. The retake below is locked until the review is done.

Below the pass mark, the learner gets a short targeted review, then a second try. Nobody has to set this up by hand for each learner.

5

The review unit

Window: remediation · open Review: Module 1.1

Show the learning objectives at the top, open one key point, then scroll to the flashcards and turn one.

Every line is copied word for word from the module's own SCORM text by a script. Nothing is written by AI. The content owner signs each unit off before learners see it; in production they stay hidden until then.

6

The retake opens

Window: remediation · back to Module 1, refresh

Viewing the review marks it complete, and the retake opens.

Review, then retake: the whole loop runs on standard Moodle completion and access rules.

3. What the teacher sees

7

The rules are ordinary Moodle settings

Window: teacher1 · Module 1.1 Knowledge Check (retake) → Settings → Restrict access

No custom engine: two standard conditions, set by a script from one configuration file for all 9 sub-modules. They back up and restore with the course.

8

Competencies

Window: teacher1 · More → Competencies

The A-FIRST framework: 9 module competencies and 35 sub-competencies. Passing a Knowledge Check or its retake records evidence, so we can report progress by competency, not only by grade.

9

Ready to measure: the pilot instruments

Window: teacher1 · Pre Course Activities

For the pilot we have built the study instruments in the course itself: information sheet, consent, questionnaires and an 18-question baseline and endline test. They are hidden, and consent unlocks the rest. They wait for the advisory team and ethics approval.

10

Optional: Phase 3 preview

Window: teacher1 · Reports → Readiness

Phase 3, READINESS, is a branching outbreak scenario. This report combines the scenario and the Knowledge Checks into three outcomes: ready for independent work, ready with supervision, or not yet ready. It stays parked until its gate.
